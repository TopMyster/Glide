https://github.com/user-attachments/assets/83275b0e-63b7-4a58-b6dd-b49ae31b2cd0

<i>It's a work in progress</i>

## Planned Features

 - Volume Controls
 - Brightness Controls
 - Media Controls
 - Specified App Controls
 - App shortcuts
 - Customizability

## Installation

1. Clone the repository: `git clone https://github.com/TopMyster/Glide`
2. Install dependencies: `npm install`
3. Run the app: `npm start`

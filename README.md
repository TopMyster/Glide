# Glide

https://github.com/user-attachments/assets/73bb7d3f-6cc1-4f88-99d9-d6b3c2a2369e

<i>It's a work in progress</i>

## Planned Features

 - Volume Controls
 - Brightness Controls
 - Media Controls
 - Specified App Controls
 - App shortcuts
 - Customizability

## Installation

1. Clone the repository: `git clone https://github.com/TopMyster/Glide`
2. Install dependencies: `npm install`
3. Run the app: `npm start`

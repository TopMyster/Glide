# Glide

The macOS touch bar for all computers, not just older Macs.

<i>It's a work in progress</i>

## Planned Features

 - Volume Controls
 - Brightness Controls
 - Media Controls
 - Specified App Controls
 - App shortcuts
 - Customizability

## Installation

1. Clone the repository: `git clone https://github.com/TopMyster/Glide`
2. Install dependencies: `npm install`
3. Run the app: `npm start`
